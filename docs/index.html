R RueyVideoEditor

A video editor you build yourself.

RueyVideoEditor is a free, open-source desktop video editor: multi-track timeline, transitions, keyframes, titles, effects and fast native FFmpeg export. There is no installer to trust. You clone the code, read it if you like, compile it, and run it.

Build & run Star on GitHub ★

Build & run in three steps

Requires Rust and the Tauri prerequisites for your platform (Xcode command-line tools on macOS, WebView2 + Visual Studio build tools on Windows, webkit2gtk on Linux). FFmpeg is found on your PATH or downloaded by the app on first launch.

# 1. Rust + Tauri CLI
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
xcode-select --install
cargo install tauri-cli --version "^2"

# 2. Clone
git clone https://github.com/rueyday/RueyVideoEditor.git rve
cd RueyVideoEditor

# 3. Run (development build) …
cargo tauri dev

# … or build an app bundle (src-tauri/target/release/bundle/)
cargo tauri build

First build takes a few minutes while Rust compiles the dependencies. After that, changes to the UI (ui/) show up on reload and changes to the engine (src-tauri/) rebuild in seconds.

What it does

Timeline

Unlimited video and audio tracks, drag to move and trim, razor, ripple delete, snapping, markers, in/out points, zoom, undo/redo.

Transform & keyframes

Position, scale, rotation, opacity and crop, all keyframable with linear or eased interpolation. Move and resize directly on the preview.

Transitions

Cross dissolve, fade to black/white, wipes, slides, circles, zoom, pixelize and more, powered by FFmpeg's xfade.

Titles & colour

Text clips with font size, weight, alignment, background box and shadow. Solid colour clips for backgrounds.

Effects

Colour correction, blur, sharpen, flip, black & white, sepia, invert, vignette, chroma key, LUTs, film grain.

Audio

Volume, fades, mute/solo per track, speed with pitch correction, detach audio from video.

Any format in

Anything FFmpeg reads: MP4, MOV, MKV, AVI, WebM, ProRes, images, MP3, WAV… Proxies keep 4K editing smooth.

Fast export

H.264, HEVC, VP9, AV1, ProRes, GIF, audio-only. Hardware encoders (VideoToolbox, NVENC, Quick Sync, AMF) when available.

Why "build it yourself"?

Downloading an unsigned binary from a stranger is a leap of faith. RueyVideoEditor doesn't ask for it. The whole editor is about ten thousand lines of readable Rust and JavaScript, with no bundler, no framework and no telemetry. Clone it, skim src-tauri/src/export.rs to see exactly what runs on your files, then compile it with the same toolchain everyone else uses. Want a feature? Add it and rebuild.

Hacking on it

  • ui/ — the interface: plain HTML, CSS and ES modules. Open ui/index.html in a browser to work on it without compiling anything.
  • src-tauri/src/export.rs — turns a project into one FFmpeg filter graph. Adding an effect is one match arm here and one entry in ui/js/model.js.
  • src-tauri/src/commands.rs — the API between the UI and the engine.
  • The README explains the architecture in detail.
