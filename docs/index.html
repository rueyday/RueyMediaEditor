The video editor you compile yourself.

A free desktop editor with a Rust + FFmpeg engine, built for research videos: multi-track timeline, side-by-side comparisons, captions, keyframes and fast native export. No installer to trust. Clone it, build it, run it.

Everything you expect

A real editor, not a toy.

The core of a non-linear editor, done properly, with the FFmpeg engine doing the heavy lifting at native speed.

Multi-track timeline

Unlimited video and audio tracks. Drag, trim, razor, ripple delete, snapping, markers, in/out points, undo history.

Transform & keyframes

Position, scale, rotation, opacity, crop and volume, all keyframable. Drag, resize and rotate right on the preview.

Transitions

Cross dissolve, fades, wipes, slides, circles and more via FFmpeg's xfade. One line to add your own.

Titles & captions

Styled text clips, a caption track, SRT import/export, and local automatic transcription with whisper.cpp.

Colour & effects

Exposure, temperature, contrast, saturation, LUTs, blur, sharpen, chroma key, grain, vignette, one-click looks.

Audio

Volume and fades with drag handles, mute/solo, detach audio, speed with pitch correction, silence removal.

Any format in

Anything FFmpeg reads: MP4, MOV, MKV, ProRes, WebM, images, audio. Proxies keep 4K smooth.

Fast export

H.264, HEVC, VP9, AV1, ProRes, GIF, audio-only or a single frame. Target a file size. Hardware encoders when available.

Made for papers and demos

Comparison videos in minutes.

The parts of a research video that usually take an afternoon in a general-purpose editor are one action here.

  • Layouts. Side by side, three across, 2×2, picture in picture. "Compare with labels" adds Baseline · Ours · Ground truth above each cell.
  • Sync by audio. Two recordings of the same run line up automatically.
  • Timecode and frame overlays, arrows, boxes, freeze frames, and a timestamped frame export for figures.
  • Venue presets. ICRA, IROS, RSS, CoRL, CVPR, NeurIPS: the export dialog warns about length and picks a bitrate that lands under the size limit.

Build & run

Three steps. No download page.

Requires Rust and the Tauri prerequisites for your platform. FFmpeg is found on your PATH or downloaded by the app on first launch.

# 1. Toolchain
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
xcode-select --install
cargo install tauri-cli --version "^2"

# 2. Clone
git clone https://github.com/rueyday/RueyMediaEditor.git
cd RueyMediaEditor

# 3. Run (or `cargo tauri build` for an .app in src-tauri/target/release/bundle/)
cargo tauri dev

First build compiles the dependencies (a few minutes). After that: edit, rebuild in seconds.

Want to change something? The interface is plain HTML, CSS and JavaScript in ui/. The engine is Rust in src-tauri/; adding an effect is one match arm. The README walks through the architecture.

Why build it yourself

Trust the code, not a binary.

Read it

About ten thousand lines, no bundler, no framework. export.rs shows exactly what runs on your footage.

Own it

Your files never leave your machine. There is nothing to sign in to and nothing that phones home.

Change it

Same toolchain as everyone else. Add the feature you need, rebuild, and send a pull request if you like.
